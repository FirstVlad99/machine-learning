## 03. Градиентный спуск: GD и SGD

**Задача:** реализовать линейную регрессию с функцией потерь MSE
и обучить её двумя методами - градиентным спуском (GD)
и стохастическим градиентным спуском (SGD), исследовать влияние
гиперпараметров на качество.

**Что сделано:**
- Реализованы классы `MyLinearRegressionGD` и `MyLinearRegressionSGD`
- Обучение моделей и оценка качества (MSE, R²).
- Исследовано влияние learning rate eta (0.0001–0.05).
- Исследовано влияние числа итераций `max_iter` (10–500).
- Построены графики сходимости.

**Результаты (базовые параметры):**

| Метод | MSE | R² |
|-------|-----|-----|
| Gradient Descent (η=0.01, max_iter=200) | 0.2797 | 0.5588 |
| Stochastic GD (η=0.005, max_iter=50) | 0.5432 | 0.1433 |

**Влияние learning rate eta (GD):**

| η | MSE | R² |
|---|-----|-----|
| 0.0001 | 34.77 | −53.83 |
| 0.001 | 5.96 | −8.40 |
| 0.01 | 0.2484 | 0.6083 |
| 0.05 | 0.2488 | 0.6076 |

**Влияние max_iter (GD):**

| max_iter | MSE | R² |
|----------|-----|-----|
| 10 | 28.38 | −43.76 |
| 50 | 5.86 | −8.24 |
| 100 | 1.02 | −0.61 |
| 200 | 0.2797 | 0.5588 |
| 500 | 0.2484 | 0.6083 |

**Выводы:**
- GD показал более высокое качество: MSE ниже, R² значительно выше -
  обновление по всей выборке даёт стабильную сходимость.
- SGD работает шумнее (обновление по объектам/батчам), качество ниже,
  требует более тщательной настройки (learning rate, эпохи, batch size)
- При малых eta модель сходится слишком медленно (отрицательный R²),
  оптимум - eta ≈ 0.01, дальнейшее увеличение даёт риск нестабильности.
- При малых `max_iter` модель не успевает сойтись, после ~200 итераций
  качество выходит на плато (сходимость достигнута).

**Файл:** `lab3.ipynb`

## 04. SVM: ядра, гиперпараметры и классификация

**Задача:** исследовать поведение SVM с разными ядрами на синтетических
выборках с разной разделимостью; применить ядра к реальной задаче
бинарной классификации (Predicting a Biological Response).

### Часть 1. Синтетические выборки (по 400+ точек)

**Что сделано:**
- Сгенерированы три двумерные выборки (`sklearn.datasets`):
  линейно разделимая, нелинейно разделимая, плохо разделимая.
- Визуализированы на плоскости.
- Обучен SVM с ядрами: линейное, полиномиальное (разные γ, d), RBF (разные γ).
- Исследовано влияние C, γ и степени d на границу решений.

**Выводы по гиперпараметрам:**

| Параметр | Малые значения | Большие значения |
|----------|----------------|------------------|
| **C** (все ядра) | мягкая граница, допускает ошибки -> недообучение | жёсткая подгонка train -> переобучение |
| **d** (полиномиальное) | d=2 - почти линейная граница | d≥8 - извилистая граница, переобучение |
| **γ** (RBF и полиномиальное) | гладкая граница, точка влияет далеко -> недообучение | резкие перегибы, локальное влияние -> переобучение |

Идеальная зона (по эксперименту): C ≈ 1–10, γ ≈ 0.01–0.1.

### Часть 2. Predicting a Biological Response

**Данные:** `train.csv`, 3751 объект * 1777 признаков (бинарная классификация).
Разбиение train/test - 50/50.

**Что сделано:**
- Обучены SVM с линейным, полиномиальным и RBF-ядром (C=1).
- Сравнение с линейной моделью.
- Подбор гиперпараметров (C, γ) и числа компонент PCA
  через `GridSearchCV` (5-fold, 36 кандидатов, 180 fits).
- Финальная модель: RBF + PCA(300) + C=3, γ=0.001.

**Результаты:**

| Модель | Accuracy (test) |
|--------|-----------------|
| Linear kernel | 0.6914 |
| Polynomial kernel | 0.5853 |
| RBF (без подбора) | ниже линейной |
| **RBF + PCA(300) + подбор (C=3, γ=0.001)** | **0.7729** |

Лучший CV score: 0.7525. Classification report (test):
precision/recall/f1 ≈ 0.77/0.77/0.77 (macro avg).

**Выводы:**
- Лучший результат - RBF после подбора гиперпараметров и PCA:
  accuracy 0.7729 (цель 0.75 достигнута).
- В данных есть нелинейные зависимости - линейная модель их не улавливает.
- PCA снизил размерность (1777 -> 300), убрал шум и улучшил обобщение.
- Полиномиальное ядро худшее: при высокой размерности отображение
  слишком сложное, растёт риск переобучения, модель чувствительна
  к степени d и γ.
- **Использование ядер позволяет достичь лучшего качества**, чем линейная
  модель (0.7729 > 0.6914).

**Файл:** `lab4.ipynb`

## 05. Bank Marketing: логистическая регрессия и RandomForest

**Задача:** предсказать, подпишется ли клиент на срочный депозит
(данные соревнования Bank Marketing); сравнить логистическую регрессию
и RandomForest, оценить влияние подбора гиперпараметров.

### Часть 1. Логистическая регрессия

**Что сделано:**
- Кодирование категориальных признаков:
  - `month`, `day_of_week`, `education` - с учётом порядка (ordinal);
  - `job` - One-Hot Encoding;
  - остальные - Label Encoding.
- Целевая переменная приведена к 1/0.
- Признаки нормализованы `MinMaxScaler`.
- Обучена логистическая регрессия; classification report + ROC-AUC.

**Результаты (baseline):**

| Класс | precision | recall | f1-score | support |
|-------|-----------|--------|----------|---------|
| 0 (не подписался) | 0.92 | 0.98 | 0.95 | 10965 |
| 1 (подписался) | 0.69 | 0.37 | 0.48 | 1392 |
| accuracy | — | — | 0.91 | 12357 |
| macro avg | 0.81 | 0.67 | 0.71 | 12357 |
| weighted avg | 0.90 | 0.91 | 0.90 | 12357 |

**ROC-AUC = 0.9294**

**Выводы:**
- Accuracy 0.91 обманчива из-за дисбаланса классов (класс 1 - ~11%).
- Класс 0 определяется отлично (precision 0.92, recall 0.98).
- Класс 1 - слабо: recall 0.37, модель пропускает большинство
  потенциальных подписчиков; f1 = 0.48.
- ROC-AUC = 0.9294 - модель хорошо разделяет классы по вероятностям,
  несмотря на низкий recall по классу 1.

### Часть 2. Подбор гиперпараметров логистической регрессии

- `GridSearchCV` по `penalty` и `C`.
- Лучшие параметры: `C=10`, `penalty='l1'`, `solver='liblinear'`.
- Best CV ROC-AUC: 0.9269; **Test ROC-AUC после подбора: 0.9311**.

**Вывод:** улучшение незначительное (0.9294 -> 0.9311) - модель уже
близка к оптимуму для этих данных, сильного выигрыша от регуляризации нет.

### Часть 3. RandomForest + подбор гиперпараметров

- `GridSearchCV` по `n_estimators` и `max_features`.
- Лучшие параметры: `n_estimators=300`, `max_features='sqrt'`.
- Best CV ROC-AUC: 0.9434; **Test ROC-AUC: 0.9453**.

**Итоговое сравнение:**

| Модель | Test ROC-AUC |
|--------|--------------|
| Logistic Regression (baseline) | 0.9294 |
| Logistic Regression (tuned) | 0.9311 |
| **RandomForest (tuned)** | **0.9453** |

**Выводы:**
- RandomForest превосходит логистическую регрессию как до, так и после
  подбора (0.9453 > 0.9311).
- В данных есть нелинейные зависимости и взаимодействия признаков,
  которые деревья улавливают лучше линейной модели.
- Подбор гиперпараметров LR дал минимальный прирост — модель уже
  оптимальна; для RF подбор дал более заметный выигрыш.

**Файл:** `lab4_logistic.ipynb`
